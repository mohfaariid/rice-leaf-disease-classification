# Folder Data

Folder ini digunakan untuk meletakkan dataset jika source code dijalankan ulang.

Dataset tidak disertakan penuh pada paket source code agar ukuran folder tetap ringan. Struktur dataset yang digunakan harus berbentuk folder per kelas, misalnya:

```text
data/
├── rice_leaf_7_original/
│   ├── Bacterial Leaf Blight/
│   ├── Brown Spot/
│   ├── Healthy Rice Leaf/
│   ├── Leaf Blast/
│   ├── Leaf Scald/
│   ├── Sheath Blight/
│   └── Tungro/
└── rice_leaf_aug_7_balanced_quality_hybrid_653/
    ├── Bacterial Leaf Blight/
    ├── Brown Spot/
    ├── Healthy Rice Leaf/
    ├── Leaf Blast/
    ├── Leaf Scald/
    ├── Sheath Blight/
    └── Tungro/
```
