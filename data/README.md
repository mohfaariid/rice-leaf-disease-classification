# Data

Folder ini disiapkan untuk menyimpan referensi data, hasil preprocessing, dan
file split.

Rekomendasi:

- `raw/`: dataset asli atau shortcut/referensi ke dataset asli.
- `processed/`: data hasil preprocessing jika nanti disimpan secara eksplisit.
- `splits/`: file daftar path gambar untuk train, validation, dan test.

Dataset asli sebaiknya tetap berada di luar folder proyek agar tidak bercampur
dengan kode.
