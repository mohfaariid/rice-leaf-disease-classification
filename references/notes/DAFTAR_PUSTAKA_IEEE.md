## Catatan Penting

1. **Format IEEE**: Referensi di atas menggunakan format IEEE. Jika universitas menginginkan format lain (APA, Chicago, dll), perlu disesuaikan.

2. **PDF Path**: Semua file PDF tersimpan di folder `references/journals/`. Pastikan path konsisten dengan struktur proyek.

3. **Author & DOI**: Untuk publikasi lengkap, perlu ekstraksi metadata lebih detail dari setiap PDF termasuk nama author, DOI, halaman, dll.

4. **Urutan Citasi**: Referensi harus diurutkan sesuai urutan kemunculan di teks (standard IEEE style).
